# Joyeria 3D - Auria Atelier

Demo de vitrina de joyeria ficticia con productos 3D interactivos: anillo, collar, aretes y brazalete.

## Ejecutar localmente

```bash
npm install
npm run dev
```

La aplicacion se abre en `http://127.0.0.1:5173/` por defecto.

## Comandos

```bash
npm run build
npm run preview
```
